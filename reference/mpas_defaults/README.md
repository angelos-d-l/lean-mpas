# MPAS 8.4.2's generated default namelists and streams

Generated by MPAS 8.4.2's build from its `Registry.xml` (MPAS-Model commit f34984b) and copied unchanged:

- `namelist.atmosphere`, `streams.atmosphere`, `stream_list.atmosphere.{output,diagnostics,surface,diag_ugwp}`: the
  `default_inputs/` of the `atmosphere` core build;
- `namelist.init_atmosphere`, `streams.init_atmosphere`: the `default_inputs/` of the `init_atmosphere` core build.

MPAS's source tree does not hold them; its build writes them. Every case spec (`cases/<case>/`) is applied to them by
`tools/cases/run_spec.py`. `SHA256SUMS` holds their sums.
