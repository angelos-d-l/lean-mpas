## Where each row comes from

- `state`: the physics state; on the card through enter_state (src/phys_dev.f90 phys_device_start, when any stage is on the card) (parsed from src/state.f90 allocate_state)
- `physics_mesh`: the physics mesh (allocate_mesh in src/state.f90), host only (parsed from src/state.f90 allocate_mesh)
- `land`: the Noah-MP state; on the card through enter_land (parsed from src/noahmp_state.f90 allocate_land)
- `land_swsplit`: the members LEAN_NOAHMP_SWSPLIT adds to the Noah-MP state (parsed from src/noahmp_state.f90 allocate_land)
- `gf`: the Grell-Freitas state (allocated with the scheme off too) (parsed from src/gf_state.f90 allocate_gf)
- `gwdo`: the GWDO state (parsed from src/gwdo_state.f90 allocate_gwdo)
- `dyn_fields`: the dynamics fields; on the card through device_enter_fields (model_device_start), horiz_flux host only (device_enter_fields in src/dyn_device.f90) (parsed from src/dyn_step.f90 allocate_fields)
- `dyn_grid`: the dynamics grid coefficients (zb_cell, zb3_cell), on the card through device_enter_grid (parsed from src/dyn_step.f90 setup_grid)
- `micro_fields`: the resident microphysics fields (allocate_micro in src/dyn_micro.f90), on the card with Thompson there (micro_enter_device) (parsed from src/dyn_micro.f90 allocate_micro)
- `dyn_mesh`: the dynamics mesh read from the mesh file (read_mesh_inputs) (parsed from src/io/lean_inputs.f90 read_mesh)
- `cold_mesh_extras`: the mesh fields the start from the init file and the checks use (run%cold) (parsed from src/io/lean_inputs.f90 read_mesh_extras)
- `cold_dyn`: the initial dynamics state of a start from the init file (cold_dyn_type) (parsed from src/io/lean_inputs.f90 read_state_inputs)
- `radiation_groups`: the g-point radiation group arrays for rad_slots columns, host arrays with their card copies (declare create), rf_allocate in src/device/radiation_fast_data.f90
- `micro_pools`: the card's column work-array pools, host arrays with their card copies (micro_pool_allocate in src/device/micro_pool.f90): micro_slots threads, GF min(gf_slots, micro_slots); staged unless LEAN_MICRO_ONEKERNEL without LEAN_MICRO_STAGED=1
- `mynn_stage`: MYNN's stage arrays by chunk (mynn_ldc columns) and plume columns (mynn_card_start in src/device/mynn_card.f90)
- `thompson_first_use`: the staged Thompson's arrays at first use (microphysics_columns in src/dyn_micro.f90, thompson_card_start in src/device/thompson.f90)
- `thompson_tables`: the Thompson tables as read (the payload of lean.lock.json's four files, real(8)); the full freezing arrays host only, their slices at the default IN on both sides (thompson_init and freezing_tables_at_default_in in src/device/thompson.f90). The slices' size is from the source (ntb_IN = 55)
- `radiation_cache`: allocate_radiation_cache in src/model_data.f90; on the card in phys_device_start. rad: 48 bytes a cell, from the source, not measured
- `coupling_work`: model_init in src/lean_model.f90; tend_th, ux, uy, east, north on the card in phys_device_start
- `monthly`: the monthly ozone and the radiation surface inputs, run_model_from in src/lean_model.f90 (greenfrac on a restart)
- `start_winds`: output_start in src/lean_fields.f90 (a start from the init file, even with outputs off)
- `mslp_work`: the two MSLP work arrays, film_fields in src/film_output.f90
- `writer_buffers`: the writer's three buffers of the largest active output (floor nCells), output_start in src/lean_fields.f90
- `writer_held`: initial(ncells, nh), the held output fields, output_start in src/lean_fields.f90
- `writer_copy`: the writer's copy scratch: the largest copied file variable (copy_var in src/io/lean_writer.f90)
- `film_in`: the reflectivity inputs of every cell for the film output (micro_film_start in src/dyn_micro.f90)
- `maxima`: the diagnostics' vertex order for the maxima (diag_resume in src/diag/diag_manager.f90), 32 bytes a cell
- `read_scratch`: the read scratch wider than eight slots (weightsOnEdge, 20 slots) and the column temporaries of the init-file input and its checks (read_columns and check_inputs in src/io/lean_inputs.f90)
- `lbc_record`: one boundary record (lbc_next in src/io/lean_lbc.f90)
- `lbc_schedule`: 512 bytes a boundary request for its file name (lbc_reader in src/io/lean_lbc.f90); the memory check leaves lbc_requests at 0, since the row stays under 1 MiB even for 1,024 requests
- `glacier_list`: the glacier columns: from the init file a list of capacity 64 x 2^k, from a restart exactly lean_nGlacierCells (start_glacier in src/land_ice.f90; restart_prepare in src/io/lean_restart.f90)
- `glacier_grow`: the old glacier list at the last doubling (start_glacier in src/land_ice.f90)
